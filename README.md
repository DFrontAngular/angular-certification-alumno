# Certificación Angular · versión alumno

Proyecto de evaluación sobre Angular general y APIs modernas, organizado en **dos jornadas**.

## Día 1 · Parte teórica · 40 puntos

1. Test general: 20 puntos.
2. Análisis de código: 20 puntos.

Al terminar el Día 1 comienza el ejercicio para casa.

## Entre jornadas · Ejercicio de casa · 30 puntos

- CRUD sencillo de usuarios con formulario, validación y testing.
- Debes entregarlo antes o al comienzo del Día 2.

## Día 2 · Parte práctica

El evaluador te entregará al comenzar la sesión el material de **live coding con tres bugs**. Ese material no se incluye en esta descarga para que el ejercicio se realice en directo.

Primero se realizará el live coding y después se revisará tu ejercicio de casa.

## Requisitos

- Node.js `^22.22.3`, `^24.15.0` o `^26.0.0`.
- npm 10 o superior.

Se incluye `.nvmrc` con Node 24.15.0.

```bash
nvs use 24.15.0
npm install
npm start
```

Comandos útiles:

```bash
npm run build
npm test
npm run test:watch
```

## Antes de empezar

Lee `docs/01_INSTRUCCIONES_ALUMNO.md` y la política de herramientas indicada por la persona evaluadora.

- Los test pueden completarse desde la aplicación o usando las versiones imprimibles de `docs/`.
- Las selecciones realizadas en la aplicación se guardan en `localStorage` y pueden exportarse como texto.
- El ejercicio de casa está en `src/app/take-home/users/`.
- Centraliza la entrega en `ENTREGA_ALUMNO.md` y adjunta el proyecto modificado.

## Importante

Este proyecto **no contiene respuestas correctas ni los bugs del Día 2**. El material de live coding será facilitado por el evaluador únicamente al comenzar esa sesión.
