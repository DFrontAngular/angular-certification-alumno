# 04 · Live coding · Día 2

El live coding se realiza durante la segunda jornada y vale **30 puntos**.

Los tres ejercicios no se incluyen en la descarga inicial. El evaluador facilitará el material al comenzar la sesión.

## Dinámica

Para cada bug se espera que puedas:

1. Reproducir el comportamiento.
2. Localizar la causa raíz.
3. Aplicar una corrección proporcionada.
4. Verificar el resultado.
5. Explicar brevemente por qué funciona.

La revisión de tu ejercicio de casa se realizará **después** del live coding.
